# My AGENTS.md

[中文](README.md) | English

I've been using this `AGENTS.md` and like how it works, so I'm sharing it here.

It covers the things I care about: give direct answers and skip the stock phrases; keep going when there's work left to do, instead of stopping at a plan; keep code changes focused, without unnecessary additions or unrelated refactoring; and explain what changed and what was checked. Don't claim to have done something you haven't done.

There's also a section on error handling. Let errors surface where they should, rather than hiding the real problem behind default values, empty results, or layers of fallbacks.

The full English version is in [AGENTS.en.md](AGENTS.en.md). If you like working this way too, feel free to use it as a starting point and adapt it to your project. To use the English version, copy or rename it to `AGENTS.md`; if your project already has that file, merge in the parts you want.
